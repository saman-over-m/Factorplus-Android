# Factor Plus Android V2 — Responsive Hardened

- رابط کاربری موبایل‌اول با bottom navigation در عرض‌های کوچک
- بدون اسکرول افقی در بدنه برنامه
- فیت خودکار پیش‌نمایش فاکتور A4/A5 با حفظ نسبت و مقیاس
- کنترل‌های لمسی حداقل 42px
- سازگار با safe-area و نوارهای سیستمی Android
- تنظیم WebView برای viewport و اندازه صحیح صفحه
- Workflow اصلاح شد و مستقیماً از `android_project` بیلد می‌گیرد.

نکته: APK را در این محیط کامپایل نکردم چون Android SDK/Gradle محلی در دسترس نیست؛ ساختار و کد با بررسی استاتیک و syntax check تست شده‌اند.
